# Vocalis – landing page

SvelteKit + Tailwind CSS 4 landing page for a fictional AI voice platform.

## Run

```sh
cd frontend
npm install
npm run dev      # http://localhost:5173
npm run build
npm run check    # svelte-check
```

(or from the repo root: `npm --prefix frontend install`, then `npm run dev`).

## Notes

- Voice previews use the browser's built-in speech synthesis; no speech API is connected.
- Download buttons, newsletter form and footer/social links are placeholders.
